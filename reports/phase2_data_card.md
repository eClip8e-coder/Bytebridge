# Phase 2 Data Card

Date: 2026-05-22

## Purpose

The Phase 2 benchmark is a small, deterministic stress suite for testing whether
ByteBridge can use noisy or tokenizer-unfriendly byte inputs to predict the same
clean target tokens as the tokenizer baseline.

## Manifest Format

Each JSONL row contains:

- `id`
- `bucket`
- `input_text`
- `target_text`
- `source`
- `perturbation_type`
- `noise_level`
- `seed`
- `clean_id`
- `clean_sha256`
- `source_id`
- `noise_recipe_id`
- input/target byte and token length fields

For noisy examples, `input_text` is perturbed and `target_text` is the clean
source text. For clean/stress examples, input and target are identical unless a
future task explicitly defines normalization.

## Caveats

This is synthetic and curated data, not a real distribution. The benchmark is
useful for falsifying claims under controlled stress, but it cannot establish
real-world robustness on its own.
